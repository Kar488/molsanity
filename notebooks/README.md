# Notebooks

## `molsanity_full_run_colab.ipynb` — full-scale run on a free Colab GPU

One-click reproduction of the complete `configs/full.yaml` sweep (150 epochs,
50 IG steps, 100 audited molecules/cell, scaffold + random splits) on a free
Colab **T4** — the publication-scale numbers the CPU dev box only approximates.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Kar488/molsanity/blob/claude/molsanity-scaffold-mutag-uayx7a/notebooks/molsanity_full_run_colab.ipynb)

- Set **Runtime → Change runtime type → T4 GPU**, then **Run all**.
- **Resumable**: committed checkpoints + stage `.done` markers are reused, so if
  the session drops, re-run the *Run the sweep* cell — it continues, no retraining.
- The notebook is generated by `make_notebook.py` (edit that, not the `.ipynb`, and
  re-run `python notebooks/make_notebook.py`).
