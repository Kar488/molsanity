# Notebooks

## `molsanity_full_run_colab.ipynb` — full-scale run on a free Colab GPU

One-click reproduction of the complete `configs/full.yaml` sweep (150 epochs,
50 IG steps, 100 audited molecules/cell, scaffold + random splits) on a free
Colab **T4** — the publication-scale numbers the CPU dev box only approximates.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Kar488/molsanity/blob/main/notebooks/molsanity_full_run_colab.ipynb)

- Set **Runtime → Change runtime type → T4 GPU**, then **Run all**.
- **The repo is private**, so the clone cell needs a GitHub token (`repo` scope).
  With the field left blank the notebook now stops there with an explicit error
  instead of continuing past a failed clone.
- A **keep-alive** cell guards against Colab's ~90-minute *idle* disconnect. It
  cannot survive closing the tab or the ~12 h max-runtime cap — mount Drive
  (cell 3) so checkpoints persist and a re-run resumes.
- The download cell packages **only run outputs** and refuses to build an
  archive if the sweep produced none.
- **Resumable**: committed checkpoints + stage `.done` markers are reused, so if
  the session drops, re-run the *Run the sweep* cell — it continues, no retraining.
- The notebook is generated by `make_notebook.py` (edit that, not the `.ipynb`, and
  re-run `python notebooks/make_notebook.py`).
